# Testfixturer

## regjeringen-rundskriv-arkiv.html

Rå HTML av Finansdepartementets rundskrivarkiv, brukt til å verifisere
`RegjeringenParser` (Fase 2, Steg B) offline.

- **Kilde:** https://www.regjeringen.no/no/dokument/dep/fin/rundskriv/arkiv/id446220/
- **Hentet via:** Wayback Machine (web.archive.org), snapshot `20260312161515`
  (originalinnhold med `id_`-suffiks, uten Wayback sin verktøylinje).
- **Hvorfor arkivert kopi:** regjeringen.no ligger bak Cloudflares
  «challenge»-beskyttelse som svarer 403 på ikke-nettleserklienter, så live
  henting fra sandkassen er ikke mulig ennå (se beslutningsloggen). Den arkiverte
  kopien har den ekte, uendrede markupen og er en legitim kilde til parser-fixtur.

Oppdater ved behov mot en nyere snapshot når live tilgang er avklart.
